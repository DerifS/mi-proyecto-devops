Proyecto DevOps con GitHub

Este sitio forma parte de una práctica de control de versiones.

Este proyecto utiliza GitHub como plataforma DevOps.

Acerca del proyecto

Este proyecto tiene como objetivo aprender y aplicar los principios de DevOps utilizando GitHub como herramienta principal.

Objetivo del proyecto

El objetivo es crear un flujo de trabajo eficiente para el desarrollo y despliegue de aplicaciones utilizando GitHub Actions, GitHub Pages y otras herramientas relacionadas.
